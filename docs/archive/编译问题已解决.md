## 技术说明

### 为什么会出现这些问题？

1. **Maven + Lombok 兼容性**
   - Maven 命令行在 Windows + Java 17 环境下对 Lombok 支持不稳定
   - 注解处理器可能无法正确运行

2. **变量名冲突**
   - `@Slf4j` 注解会生成 `private static final Logger log`
   - 局部变量 `log` 会覆盖这个 logger 对象
   - 导致 `log.info()` 调用失败

### 解决方案

1. **使用 IDEA 内置编译器**
   - IDEA 对 Lombok 有原生支持
   - 不依赖 Maven 的注解处理器
   - 编译速度更快，更稳定

2. **避免变量名冲突**
   - 使用具体的类型名：`usageLog` 而不是 `log`
   - 遵循 Java 命名规范
