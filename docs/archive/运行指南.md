# 🚀 家庭智慧药箱管理系统 - 运行指南

## 📋 快速开始（3步启动）

### 第1步：初始化数据库

双击运行 `init-database.bat`

或手动执行：
```bash
# 在MySQL中执行
CREATE DATABASE medicine_cabinet CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

# 执行建表脚本
mysql -u root -p medicine_cabinet < src/main/resources/sql/schema.sql
```

### 第2步：配置数据库连接

编辑 `src/main/resources/application.yml`：
```yaml
spring:
  datasource:
    username: root          # 你的MySQL用户名
    password: your_password # 你的MySQL密码
```

### 第3步：启动服务

**启动后端**：
- 双击运行 `start-backend.bat`
- 或执行：`mvn spring-boot:run`
- 访问：http://localhost:8080/api

**启动前端**（可选）：
- 双击运行 `start-frontend.bat`
- 或执行：`cd frontend && npm run dev`
- 访问：http://localhost:3000

## ⚠️ 重要提示

### Java版本要求

**项目要求**：Java 17+  
**当前系统**：Java 8

**必须升级Java！** 否则无法编译运行。

#### 如何升级Java到17？

1. **下载Java 17**
   - 访问：https://adoptium.net/temurin/releases/?version=17
   - 选择：Windows x64, JDK 17 (LTS)
   - 下载并安装

2. **设置环境变量**
   ```cmd
   # 以管理员身份运行命令提示符
   setx JAVA_HOME "C:\Program Files\Eclipse Adoptium\jdk-17.0.9.9-hotspot" /M
   setx PATH "%JAVA_HOME%\bin;%PATH%" /M
   ```

3. **验证安装**
   ```bash
   java -version
   # 应显示: openjdk version "17.0.x"
   ```

### 前端实现说明

前端采用**文档化实现方案**，需要手动创建文件。

**完整实现文档**：`frontend/FRONTEND_IMPLEMENTATION.md`

**关键步骤**：
1. 查看 `frontend/FRONTEND_IMPLEMENTATION.md`
2. 创建文档中列出的所有文件
3. 复制对应的代码到各个文件
4. 运行 `npm install` 安装依赖
5. 运行 `npm run dev` 启动服务

## ❓ 常见问题

### Q1: 编译错误 "无效的标记: --release"
**原因**：Java版本过低  
**解决**：升级Java到17

### Q2: 数据库连接失败
**原因**：MySQL未启动或配置错误  
**解决**：
1. 启动MySQL服务
2. 检查 `application.yml` 中的配置

### Q3: 端口8080已被占用
**解决**：修改 `application.yml` 中的端口号

### Q4: Maven下载依赖很慢
**解决**：配置阿里云镜像
```xml
<!-- ~/.m2/settings.xml -->
<mirrors>
  <mirror>
    <id>aliyun</id>
    <url>https://maven.aliyun.com/repository/public</url>
    <mirrorOf>central</mirrorOf>
  </mirror>
</mirrors>
```

### Q5: npm install 很慢
**解决**：使用淘宝镜像
```bash
npm config set registry https://registry.npmmirror.com
```
