## 技术要点

### Lombok 变量名冲突
```java
// ❌ 错误
@Slf4j
class MyService {
    void method() {
        UsageLog log = new UsageLog();  // 与 @Slf4j 的 log 冲突
    }
}

// ✅ 正确
@Slf4j
class MyService {
    void method() {
        UsageLog usageLog = new UsageLog();  // 使用具体名称
        log.info("This works!");  // Lombok 的 logger
    }
}
```

### Spring Boot 主类语法
```java
// ❌ 错误
SpringApplication.run(MedicineCabinetApplication.java, args);

// ✅ 正确
SpringApplication.run(MedicineCabinetApplication.class, args);
```

### jqwik 测试 Mock 对象
```java
// ❌ 错误 - jqwik 不支持
@SpringBootTest
class MyTest {
    @MockBean
    private MyMapper mapper;
}

// ✅ 正确 - 手动创建 mock
class MyTest {
    @Property
    void test() {
        MyMapper mapper = mock(MyMapper.class);
    }
}
```
