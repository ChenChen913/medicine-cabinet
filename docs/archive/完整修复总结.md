## 技术要点总结

### 1. Lombok 变量名冲突

**问题**：
```java
@Slf4j  // 生成 private static final Logger log
class MyService {
    void method() {
        UsageLog log = new UsageLog();  // ❌ 覆盖了 Lombok 的 log
        log.info("...");  // ❌ UsageLog 没有 info() 方法
    }
}
```

**解决**：
```java
@Slf4j
class MyService {
    void method() {
        UsageLog usageLog = new UsageLog();  // ✅ 使用具体名称
        log.info("...");  // ✅ 使用 Lombok 的 logger
    }
}
```

### 2. Spring Boot 主类语法

**错误**：
```java
SpringApplication.run(MedicineCabinetApplication.java, args);  // ❌
```

**正确**：
```java
SpringApplication.run(MedicineCabinetApplication.class, args);  // ✅
```

### 3. jqwik 测试 Mock 对象

**错误**：
```java
@SpringBootTest  // ❌ jqwik 不支持
class MyTest {
    @MockBean  // ❌ 不会被注入
    private MyMapper mapper;
}
```

**正确**：
```java
class MyTest {
    @Property
    void test() {
        MyMapper mapper = mock(MyMapper.class);  // ✅ 手动创建
    }
}
```

### 4. MyBatis-Plus 版本兼容性

**问题**：
```xml
<mybatis-plus.version>3.5.5</mybatis-plus.version>  <!-- ❌ 与 Spring Boot 3.2.0 不兼容 -->
```

**解决**：
```xml
<mybatis-plus.version>3.5.7</mybatis-plus.version>  <!-- ✅ 兼容 -->
```
