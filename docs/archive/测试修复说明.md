# 测试修复说明

## 问题描述

运行 `mvn test` 时出现测试失败：

```
Tests run: 7, Failures: 0, Errors: 1, Skipped: 0
```

**失败的测试**：`InventoryPropertyTest.inventoryDeductionInvariant`

**错误信息**：
```
java.lang.NullPointerException: Cannot invoke "com.family.medicinecabinet.mapper.MedicineMapper.selectById(java.io.Serializable)" because "this.medicineMapper" is null
```

---

## 根本原因

`InventoryPropertyTest` 使用了 `@SpringBootTest` 和 `@MockBean` 注解，但 jqwik 的 `@Property` 测试不会自动注入 Spring 的 mock beans。

### 问题代码：

```java
@SpringBootTest  // ❌ jqwik 不支持 Spring 上下文
@PropertyDefaults(tries = 100)
public class InventoryPropertyTest {
    
    @MockBean  // ❌ 不会被注入
    private MedicineMapper medicineMapper;
    
    @MockBean
    private UsageLogMapper usageLogMapper;
    
    @MockBean
    private ShoppingListMapper shoppingListMapper;
    
    @Property
    void inventoryDeductionInvariant(...) {
        // medicineMapper 是 null！
        when(medicineMapper.selectById(...)).thenReturn(...);
    }
}
```

---

## 解决方案

移除 `@SpringBootTest` 和 `@MockBean`，在每个测试方法中手动创建 mock 对象。

### 修复后的代码：

```java
@PropertyDefaults(tries = 100)  // ✅ 移除 @SpringBootTest
public class InventoryPropertyTest {
    // ✅ 移除类级别的 @MockBean 字段
    
    @Property
    void inventoryDeductionInvariant(...) {
        // ✅ 在方法内创建 mock 对象
        MedicineMapper medicineMapper = mock(MedicineMapper.class);
        UsageLogMapper usageLogMapper = mock(UsageLogMapper.class);
        ShoppingListMapper shoppingListMapper = mock(ShoppingListMapper.class);
        
        // ✅ 传递 mock 对象到服务
        InventoryService service = createInventoryService(
            medicineMapper, usageLogMapper, shoppingListMapper
        );
        
        // 现在 mock 对象可以正常工作
        when(medicineMapper.selectById(...)).thenReturn(...);
    }
}
```

## 为什么这样修复？

### jqwik vs JUnit + Spring

| 特性 | JUnit + Spring | jqwik |
|------|---------------|-------|
| Spring 上下文 | ✅ 支持 `@SpringBootTest` | ❌ 不支持 |
| 依赖注入 | ✅ 支持 `@Autowired`, `@MockBean` | ❌ 不支持 |
| 测试方法 | `@Test` | `@Property` |
| Mock 对象 | 类级别 `@MockBean` | 方法内 `mock()` |

### 最佳实践

对于 jqwik 属性测试：
1. ✅ 不使用 `@SpringBootTest`
2. ✅ 在测试方法内创建 mock 对象
3. ✅ 使用 `Mockito.mock()` 而不是 `@MockBean`
4. ✅ 保持测试独立，不依赖 Spring 上下文
