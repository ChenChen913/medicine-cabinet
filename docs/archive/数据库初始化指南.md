# 📊 数据库初始化指南

## 前提条件

在启动应用之前，必须先初始化数据库。

---

## 步骤 1：启动 MySQL 服务

### Windows 系统

**方法 1：使用服务管理器**
1. 按 `Win + R`，输入 `services.msc`，回车
2. 找到 `MySQL` 或 `MySQL80` 服务
3. 右键点击，选择 **启动**

**方法 2：使用命令行**
```cmd
net start MySQL80
```

### 验证 MySQL 是否运行

打开命令行，输入：
```cmd
mysql -u root -p
```

输入密码（默认是 `root`），如果能登录，说明 MySQL 正在运行。

---

## 步骤 2：创建数据库

### 方法 1：使用命令行

1. 登录 MySQL：
```cmd
mysql -u root -p
```

2. 创建数据库：
```sql
CREATE DATABASE IF NOT EXISTS medicine_cabinet 
CHARACTER SET utf8mb4 
COLLATE utf8mb4_unicode_ci;
```

3. 验证数据库已创建：
```sql
SHOW DATABASES;
```

应该能看到 `medicine_cabinet` 数据库。

4. 退出 MySQL：
```sql
EXIT;
```

### 方法 2：使用 Navicat 或其他 GUI 工具

1. 打开 Navicat
2. 连接到 MySQL 服务器
3. 右键点击连接，选择 **新建数据库**
4. 数据库名：`medicine_cabinet`
5. 字符集：`utf8mb4`
6. 排序规则：`utf8mb4_unicode_ci`
7. 点击 **确定**

---

## 步骤 3：执行数据库脚本

### 方法 1：使用命令行

1. 在项目根目录打开命令行

2. 执行 SQL 脚本：
```cmd
mysql -u root -p medicine_cabinet < src/main/resources/sql/schema.sql
```

3. 输入密码（默认是 `root`）

4. 验证表已创建：
```cmd
mysql -u root -p medicine_cabinet -e "SHOW TABLES;"
```

应该看到以下表：
- `medicines`
- `categories`
- `medicine_categories`
- `usage_logs`
- `shopping_list`

### 方法 2：使用 Navicat

1. 打开 Navicat，连接到 MySQL
2. 双击 `medicine_cabinet` 数据库
3. 点击顶部菜单：**文件 → 运行 SQL 文件**
4. 选择：`src/main/resources/sql/schema.sql`
5. 点击 **开始**
6. 查看左侧的表列表，确认表已创建

### 方法 3：使用 IDEA 的数据库工具

1. 在 IDEA 中，点击右侧的 **Database** 标签
2. 点击 **+** → **Data Source** → **MySQL**
3. 配置连接：
   - Host: `localhost`
   - Port: `3306`
   - Database: `medicine_cabinet`
   - User: `root`
   - Password: `root`
4. 点击 **Test Connection**，确保连接成功
5. 点击 **OK**
6. 在 Database 面板中，右键 `medicine_cabinet` 数据库
7. 选择：**Run SQL Script**
8. 选择：`src/main/resources/sql/schema.sql`
9. 点击 **Execute**

---

## 步骤 4：验证数据库配置

### 检查 application.yml

打开 `src/main/resources/application.yml`，确认配置正确：

```yaml
spring:
  datasource:
    driver-class-name: com.mysql.cj.jdbc.Driver
    url: jdbc:mysql://localhost:3306/medicine_cabinet?useUnicode=true&characterEncoding=utf8&useSSL=false&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true
    username: root
    password: root
```

**如果你的 MySQL 配置不同，请修改**：
- `username`: 你的 MySQL 用户名
- `password`: 你的 MySQL 密码
- `localhost:3306`: 如果 MySQL 运行在其他主机或端口

## 步骤 5：测试数据库连接

### 方法 1：使用 IDEA 运行测试

1. 在项目视图中找到：`src/test/java`
2. 右键点击 `java` 文件夹
3. 选择：**运行 'All Tests'**
4. 如果测试通过，说明数据库连接正常

### 方法 2：使用命令行

```cmd
mysql -u root -p medicine_cabinet -e "SELECT 1;"
```

如果返回结果，说明数据库连接正常。

## 常见问题

### 问题 1：MySQL 服务无法启动

**错误信息**：
```
服务没有响应控制功能
```

**解决方案**：
1. 检查 MySQL 是否已安装
2. 重新安装 MySQL
3. 检查端口 3306 是否被占用

### 问题 2：无法连接到 MySQL

**错误信息**：
```
Access denied for user 'root'@'localhost'
```

**解决方案**：
1. 检查用户名和密码是否正确
2. 重置 MySQL root 密码
3. 检查 MySQL 用户权限

### 问题 3：数据库不存在

**错误信息**：
```
Unknown database 'medicine_cabinet'
```

**解决方案**：
1. 执行步骤 2，创建数据库
2. 检查数据库名称拼写是否正确

### 问题 4：表不存在

**错误信息**：
```
Table 'medicine_cabinet.medicines' doesn't exist
```

**解决方案**：
1. 执行步骤 3，运行 SQL 脚本
2. 检查脚本是否执行成功
