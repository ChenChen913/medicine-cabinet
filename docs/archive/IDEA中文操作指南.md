# IntelliJ IDEA 中文版操作指南

## 🎯 重要配置（一次性设置）

### 步骤 1：配置 Maven 不委托给命令行

1. 打开 **文件 → 设置**（或按 `Ctrl + Alt + S`）
2. 在左侧菜单找到：**构建、执行、部署 → 构建工具 → Maven → 运行程序**
3. 找到选项：**将 IDE 构建/运行操作委托给 Maven**
4. **取消勾选** 这个选项 ⭐ 非常重要！
5. 点击 **应用** 和 **确定**

### 步骤 2：启用注解处理器

1. 在设置中，找到：**构建、执行、部署 → 编译器 → 注解处理器**
2. 确保勾选：**启用注解处理**
3. 点击 **应用** 和 **确定**

### 步骤 3：验证 Lombok 插件

1. 在设置中，找到：**插件**
2. 搜索 "Lombok"
3. 确保 **Lombok** 插件已安装并启用
4. 如果没有，点击 **安装** 并重启 IDEA

## 🚀 运行应用（每次启动）

### 方法 1：右键运行（最简单）⭐⭐⭐⭐⭐

1. 在左侧项目视图中，展开文件夹：
   ```
   src → main → java → com.family.medicinecabinet
   ```

2. 找到文件：**MedicineCabinetApplication.java**

3. **右键点击** 这个文件

4. 在弹出菜单中选择：**运行 'MedicineCabinetApplication'**
   - 或者选择：**调试 'MedicineCabinetApplication'**（如果需要调试）

5. 查看底部的 **运行** 窗口，应该看到：
   ```
   Started MedicineCabinetApplication in X seconds
   Tomcat started on port(s): 8080 (http)
   ```

### 方法 2：使用顶部运行按钮

1. 第一次运行后，顶部工具栏会出现运行配置下拉框
2. 确保选中：**MedicineCabinetApplication**
3. 点击绿色的 **▶ 运行** 按钮
4. 或点击绿色的 **🐛 调试** 按钮

### 方法 3：使用快捷键

- **Shift + F10** - 运行
- **Shift + F9** - 调试

## 🧪 运行测试

### 运行所有测试

1. 在左侧项目视图中，找到：
   ```
   src → test → java
   ```

2. **右键点击** `java` 文件夹

3. 选择：**运行 'All Tests'**（运行所有测试）

4. 查看底部的 **运行** 窗口，应该看到：
   ```
   Tests run: 7, Failures: 0, Errors: 0
   ```

### 运行单个测试类

1. 找到测试文件，例如：
   ```
   src → test → java → com.family.medicinecabinet.property → InventoryPropertyTest.java
   ```

2. **右键点击** 测试文件

3. 选择：**运行 'InventoryPropertyTest'**

## 🔨 重新构建项目

### 完全重新构建

1. 点击顶部菜单：**构建 → 重新构建项目**
2. 等待构建完成
3. 查看底部的 **构建** 窗口

### 清理项目

1. 点击顶部菜单：**构建 → 清理项目**
2. 然后再：**构建 → 重新构建项目**

## 📦 Maven 面板操作

### 打开 Maven 面板

1. 点击右侧边栏的 **Maven** 标签
2. 或者：**视图 → 工具窗口 → Maven**

### 常用 Maven 命令

在 Maven 面板中，展开 **生命周期**，双击以下命令：

| 命令 | 中文说明 | 什么时候用 |
|------|---------|-----------|
| **clean** | 清理 | 删除 target 目录 |
| **compile** | 编译 | 编译主代码 |
| **test** | 测试 | 运行所有测试 |
| **package** | 打包 | 生成 jar 文件 |
| **install** | 安装 | 安装到本地仓库 |

### 刷新 Maven 项目

1. 在 Maven 面板顶部
2. 点击 **🔄 重新加载所有 Maven 项目** 按钮
3. 用于：修改 pom.xml 后刷新依赖

## ❌ 常见问题

### 问题 1：找不到 Maven 面板

**解决**：
1. 点击顶部菜单：**视图 → 工具窗口 → Maven**
2. 或者点击右侧边栏的 **Maven** 标签

### 问题 2：运行按钮是灰色的

**解决**：
1. 确保已经打开了 Java 文件
2. 确保文件包含 `main` 方法
3. 尝试：**运行 → 编辑配置** 手动创建运行配置

### 问题 3：编译错误

**解决**：
1. 点击：**文件 → 使缓存无效/重启**
2. 选择：**使缓存无效并重启**
3. IDEA 重启后，重新构建项目

### 问题 4：Lombok 不生效

**解决**：
1. 检查 Lombok 插件是否安装
2. 检查注解处理器是否启用
3. 重新构建项目

## 📝 完整操作流程（推荐）

### 每次修改代码后：

```
1. 保存文件（Ctrl + S）
   ↓
2. 构建项目（Ctrl + F9）
   ↓
3. 运行测试（右键 test 文件夹 → 运行所有测试）
   ↓
4. 运行应用（Shift + F10）
   ↓
5. 测试功能
```

### 提交代码前：

```
1. 构建 → 清理项目
   ↓
2. 构建 → 重新构建项目
   ↓
3. 运行所有测试
   ↓
4. 确认无错误
   ↓
5. 提交代码
```

## 🎯 重点提示

### ⭐ 最重要的配置

**文件 → 设置 → 构建、执行、部署 → 构建工具 → Maven → 运行程序**

**取消勾选**：将 IDE 构建/运行操作委托给 Maven

这是解决所有 Lombok 和 MyBatis-Plus 问题的关键！

```
修改代码 → 保存 → 构建 → 测试 → 运行 → 验证
```
