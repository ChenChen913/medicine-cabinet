## 🚀 快速启动

### 方式1：使用批处理脚本（推荐）

```bash
# 1. 初始化数据库
init-database.bat

# 2. 启动后端
start-backend.bat

# 3. 启动前端
start-frontend.bat
```

### 方式2：手动启动

**后端：**
```bash
# 创建数据库
mysql -u root -p
CREATE DATABASE medicine_cabinet CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

# 执行建表脚本
mysql -u root -p medicine_cabinet < src/main/resources/sql/schema.sql

# 修改配置（src/main/resources/application.yml）

# 启动后端
mvn spring-boot:run
```

**前端：**
```bash
cd frontend
npm install
npm run dev
```

## ⚠️ 注意事项

### 1. Java版本
- **要求**：Java 17+
- **当前**：系统可能是Java 8
- **解决**：升级Java或使用 `pom-java8.xml.backup`

### 2. 数据库配置
修改 `src/main/resources/application.yml`：
```yaml
spring:
  datasource:
    username: root          # 修改为你的MySQL用户名
    password: your_password # 修改为你的MySQL密码
```

### 3. 端口占用
- 后端默认端口：8080
- 前端默认端口：3000
- 如有冲突，请修改配置文件
